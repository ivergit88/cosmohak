# Демо-сценарий (~3 минуты)

Подготовка: открыть приложение (`streamlit run app.py`), заранее ничего
не настраивать. Сценарий 01 загружается автоматически и считается сам.

| # | Действие | Что сказать | Что видно |
|---|---|---|---|
| 1 | Открыт сценарий «Полная группировка» | «Сервис загрузил сценарий и сам выполнил расчёт на 720 отсчётов» | Карточки: C65 96.7%, C70 98.8%, C72 98.9%, цель 90% достигнута |
| 2 | Вкладка «Сеть и время», выбрать t≈12:00 | «Маршрут строится на каждом отсчёте» | 3D-сцена: Земля, 48 спутников, связи, маршрут C65 → … → G_MUR |
| 3 | Двигать слайдер времени | «Маршрут перестраивается при движении аппаратов» | Цепочка ID меняется, число переходов 2–5 |
| 4 | Кнопка «Перерыв ▶» | «А если маршрута нет — сервис называет причину» | «Маршрута нет 17:04:00: нет видимого спутника» |
| 5 | Навести на таймлайн | «Каждый перерыв классифицирован: видимость / шлюз / ISL» | Теплокарта состояний по всем пунктам |
| 6 | Сбросить этап развёртывания 3 → 1, «Пересчитать» | «Ранняя очередь: группировка не закрывает север» | Доступность падает до 12–27%, перерывы до 13 часов |
| 7 | Вернуть этап 3; в «Устойчивости» запустить критичность | «Автоматический поиск single points of failure» | Топ-10 аппаратов по Δmin доступности |
| 8 | «➕ Добавить отказ» для спутника из текущего маршрута → «Пересчитать» | «Отказ спутника из маршрута: сеть перестраивается или возникает перерыв» | Новый маршрут или новый перерыв с причиной |
| 9 | «💾 Сохранить вариант», изменить RAAN плоскости P1 на 30°, пересчитать, сохранить второй вариант | «Проектные варианты сравниваются по одним условиям» | Вариант 1 и Вариант 2 в списке |
| 10 | Вкладка «Сравнение», выбрать варианты | «Рекомендация связана с расчётом, а не с магическим score» | Таблицы различий, Δ метрик, критерий лексикографический |
| 11 | Вкладка «Экспорт» → Download result JSON | «Маршрут для каждой пары отсчёт × пункт — 2160 записей, формат cosmo-A-result-1.0» | Скачанный файл; его effective scenario можно загрузить обратно |

Резерв (если останется время): вкладка «Устойчивость» → «Что если» — отказ
одного аппарата с таблицей Δ по пунктам; быстрый подбор RAAN/фазирования.

Ответы на вероятные вопросы — в docs/TECHNICAL_QA.md.
